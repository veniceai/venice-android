# Venice for Android

This repository publishes the full-feature Android build of [Venice](https://venice.ai) as an APK.

This build includes features that aren't available in the [Google Play version](https://play.google.com/store/apps/details?id=com.ai.venice). If you'd rather install from a store, use Google Play or the [App Store](https://apps.apple.com/app/id6742061900).

## Download

[Download the latest APK](https://github.com/veniceai/venice-android/releases/latest/download/venice.apk)

All versions are listed under [Releases](https://github.com/veniceai/venice-android/releases). Each release is published automatically from the Venice mobile build and lists the SHA-256 checksum of its APK.

## Install

1. Download `venice.apk` on your Android phone.
2. Open the file. If Android asks, allow installs from your browser.
3. Tap Install, then open Venice and sign in.

## Verify the download

Compare the file's checksum with the one in the release notes:

```
sha256sum venice.apk        # Linux
shasum -a 256 venice.apk    # macOS
```
